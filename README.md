# 仮想東海道五十三次ラリー｜歩いて京へ

構成: GitHub Pages（フロント）+ Google Apps Script（バックエンド）+ Googleスプレッドシート（会員・記録データ）+ Googleドライブ（写真）+ Gemini API（旅の一言コメント生成）

会員登録・ログイン・仮パスワード発行・強制パスワード変更・パスワード再発行・5回失敗ロック、というお馴染みの会員認証システムを実装しています。

## ファイル構成
```
index.html   … 画面本体（ログイン/登録/記録フォーム/タイムライン）
style.css    … スタイル
auth.js      … 会員認証まわり
app.js       … 記録投稿・進捗表示
gas/Code.gs  … GASバックエンド（このままGASプロジェクトに貼り付け）
```

## セットアップ手順

### 1. Googleスプレッドシートを新規作成
- 空のスプレッドシートを1つ作成し、URLからスプレッドシートIDを控えておく（`members`/`records`シートはコードが自動生成します）

### 2. Googleドライブに写真保存用フォルダを作成
- 新規フォルダを1つ作成し、フォルダIDを控えておく

### 3. Gemini APIキーを取得
- Google AI Studio等でAPIキーを発行

### 4. GASプロジェクトを作成
1. 上記スプレッドシートの「拡張機能」→「Apps Script」を開く
2. `Code.gs` の中身を、このリポジトリの `gas/Code.gs` の内容に置き換える
3. 左メニュー「プロジェクトの設定」→「スクリプト プロパティ」に以下を追加
   - `SPREADSHEET_ID` … 1で控えたスプレッドシートID
   - `DRIVE_FOLDER_ID` … 2で控えたフォルダID
   - `GEMINI_API_KEY` … 3で取得したAPIキー
   - `PEPPER` … 任意のランダムな文字列（パスワードハッシュ用の秘密の味付け。自分で決めてOK）
4. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」
   - 実行するユーザー: 自分
   - アクセスできるユーザー: 全員
5. 発行された「ウェブアプリURL」（`.../exec` で終わるもの）を控える

### 5. フロントの設定を書き換え
- `auth.js` 冒頭の `API_URL` を、4で控えたウェブアプリURLに書き換える

### 6. GitHub Pagesへ公開
- `index.html` / `style.css` / `auth.js` / `app.js` をリポジトリ直下に配置してPush
- リポジトリの Settings → Pages で公開

## 注意点
- GASのコードを変更したら、都度「デプロイ」→「デプロイを管理」→ 新しいバージョンとして再デプロイが必要です（URLは変わりません）
- 会員登録・パスワード再発行時のメール送信には `MailApp` を使用しています（1日あたりの送信数上限に注意）
- 写真はGoogleドライブに保存し、「リンクを知っている全員が閲覧可」で共有した上でURLをスプレッドシートに記録しています
